# Руководство по настройке сервера Nukkit с нуля

Добро пожаловать в руководство по настройке сервера Nukkit! Оно проведёт вас через процесс настройки **сервера Nukkit** с нуля, что позволит вам запустить собственный **сервер Minecraft Bedrock Edition**.

## Содержание руководства

Это руководство разбито на несколько глав для удобства использования:

### 📖 Навигация по главам

1. **[Подготовка](getting-started/preparation.md)**
   Узнайте о системных требованиях и установите среду выполнения Java

2. **[Скачивание и установка](getting-started/installation.md)**
   Скачайте Nukkit-MOT, создайте папку сервера и скрипт запуска

3. **[Настройка сервера](getting-started/configuration.md)**
   Настройте параметры сервера и измените игровые настройки

4. **[Установка плагинов](getting-started/plugins.md)**
   Расширьте функциональность сервера, устанавливайте плагины и управляйте ими

5. **[Подключение к серверу](getting-started/connect.md)**
   Позвольте игрокам присоединяться к вашему серверу

6. **[Устранение неполадок](getting-started/troubleshooting.md)**
   Решите распространённые проблемы, возникающие при настройке

## Быстрый старт

Если хотите быстро опробовать сервер, выполните следующие минимальные шаги:

1. **Установите Java 17+** — [Подготовка](getting-started/preparation.md)
2. **Скачайте Nukkit-MOT** — [ссылка для скачивания](https://motci.cn/job/Nukkit-MOT/job/master/lastSuccessfulBuild/artifact/target/Nukkit-MOT-SNAPSHOT.jar)
3. **Создайте скрипт запуска** — см. [руководство по установке](getting-started/installation.md)
4. **Запустите сервер** — дважды щёлкните по скрипту, чтобы запустить его
5. **Подключитесь к игре** — используйте `127.0.0.1:19132`
