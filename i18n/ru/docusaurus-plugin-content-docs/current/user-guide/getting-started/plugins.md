# Установка плагинов

Nukkit поддерживает расширение функциональности сервера с помощью плагинов, например добавление новых игровых механик, инструментов управления, экономических систем и т. д.

## Хотите создать собственный плагин?

Если вы хотите разработать плагин, а не устанавливать готовый, начните со статьи [Первый плагин на Java](../../developer-guide/tutorial-basics/frist_java_plugin), а затем продолжите с [Основ плагинов](../../developer-guide/tutorial-basics/plugin-basics).

## Где получить плагины

Скачать плагины для Nukkit можно из следующих источников:

- [Cloudburst (форум Nukkit)](https://cloudburstmc.org/resources/categories/nukkit-plugins.1/) — официальный репозиторий плагинов
- [MineBBS](https://www.minebbs.com/resources/categories/nukkit.40/) — репозиторий плагинов китайского сообщества
- [GitHub](https://github.com/) — поиск проектов плагинов с открытым исходным кодом

:::tip Советы
При скачивании плагинов обратите внимание:
- Убедитесь, что плагин поддерживает вашу версию Nukkit
- Проверьте зависимости плагина
- Прочитайте инструкции по использованию плагина
:::

## Установка плагинов

### Шаги установки

1. **Скачайте файл плагина**
   - Файлы плагинов обычно имеют формат `.jar`

2. **Разместите плагин**
   - Поместите скачанный файл `.jar` в папку `plugins` на сервере
   - Если папки `plugins` не существует, создайте её вручную

3. **Перезапустите сервер**
   - Сохраните все изменения и выключите сервер
   - Перезапустите сервер, чтобы загрузить новые плагины

### Проверка установки плагина

После запуска сервера введите в консоли:

```
plugins
```

Или сокращённый вариант:

```
pl
```

Вы увидите список установленных плагинов:

- **Зелёное название плагина**: плагин успешно загружен
- **Красное название плагина**: плагин не удалось загрузить

:::warning Обратите внимание
Если название плагина отображается красным, проверьте:
- Совместим ли плагин с текущей версией Nukkit
- Не отсутствуют ли зависимые плагины
- Нет ли сообщений об ошибках в консоли
:::

## Настройка плагинов

Большинство плагинов автоматически создают файлы конфигурации при первой загрузке, обычно они находятся по пути:

```
plugins/PluginName/config.yml
```

Вы можете изменять файлы конфигурации в соответствии с документацией плагина. После изменения необходимо:
- Перезапустить сервер, или
- Использовать команду перезагрузки плагина (если она поддерживается)

## Управление плагинами

### Просмотр списка плагинов

```
plugins
```

### Перезагрузка плагина (поддерживается не всеми плагинами)

```
reload
```

:::caution Предупреждение
Частое использование команды `reload` может привести к утечкам памяти и другим проблемам. Рекомендуется вместо этого перезапускать сервер.
:::

### Удаление плагина

1. Остановите сервер
2. Удалите файл плагина `.jar` из папки `plugins`
3. Удалите папку конфигурации плагина (необязательно)
4. Перезапустите сервер
