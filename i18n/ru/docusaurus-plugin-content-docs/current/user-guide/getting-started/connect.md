# Подключение к серверу

После успешного запуска сервера вы можете подключиться к нему с помощью клиента Minecraft Bedrock Edition.

## Проверка состояния сервера

Перед подключением убедитесь, что:

1. **Сервер полностью запущен**
   - В консоли отображается `Done (xx.xxs)! For help, type "help"`

2. **Сервер работает**
   - Консоль нормально принимает команды

## Способы подключения

### Локальное подключение (тот же компьютер)

Если вы играете на том же компьютере, где работает сервер:

1. Откройте клиент Minecraft Bedrock Edition
2. Нажмите «Играть» → «Серверы» → «Добавить сервер»
3. Заполните информацию о сервере:
   - **Название сервера**: произвольное имя
   - **Адрес сервера**: `127.0.0.1` или `localhost`
   - **Порт**: `19132` (порт по умолчанию; если он был изменён, укажите актуальный)
4. Нажмите «Сохранить» и подключитесь

:::warning Замечание о локальном подключении в Windows 10/11
В Windows по умолчанию включены ограничения петлевого интерфейса (loopback), которые необходимо снять для локальных подключений:

1. Запустите PowerShell от имени администратора
2. Выполните следующую команду:
```powershell
CheckNetIsolation LoopbackExempt -a -n="Microsoft.MinecraftUWP_8wekyb3d8bbwe"
```
:::

### Подключение по локальной сети (одна сеть)

Если вы и сервер находитесь в одной локальной сети:

1. Узнайте локальный IP-адрес сервера:
   - **Windows**: выполните команду `ipconfig` в командной строке и найдите IPv4-адрес
   - **Linux/macOS**: выполните `ifconfig` или `ip addr` в терминале

2. В клиенте Minecraft укажите:
   - **Адрес сервера**: локальный IP-адрес сервера (например, `192.168.1.100`)
   - **Порт**: `19132` (или пользовательский порт)

### Подключение через публичную сеть (удалённый сервер)

Если сервер развёрнут на удалённом хостинге или облачном сервере:

1. **Узнайте публичный IP**
   - Спросите администратора сервера или проверьте консоль облачного сервера

2. **Настройте межсетевой экран**
   - Убедитесь, что межсетевой экран разрешает входящие подключения по **UDP-порту 19132**
   - Также откройте **TCP-порт 19132** для [NetherNet](../server-config/nukkit-mot-yml.mdx) — транспорта на WebRTC, который по умолчанию используется клиентами с Bedrock 1.26.50
   - Медиатрафик NetherNet (игровые данные WebRTC) по умолчанию использует **UDP-порт 19134** — если порт изменён, см. [`server-udp-ports`](../server-config/server-properties.mdx#server-udp-ports)
   - Для облачных серверов необходимо открыть порт в группах безопасности

3. **Настройте проброс портов** (при необходимости)
   - Если сервер находится за маршрутизатором, необходимо настроить проброс портов

4. Заполните в клиенте:
   - **Адрес сервера**: публичный IP
   - **Порт**: `19132` (или пользовательский порт)

## Поддерживаемые клиенты

Сервер Nukkit поддерживает следующие клиенты Bedrock Edition:

- Minecraft Bedrock Edition (Windows 10/11)
- Minecraft PE (Android/iOS)
- Minecraft (Nintendo Switch)
- Minecraft (Xbox)
- Minecraft (PlayStation)
- **NetEase Minecraft** (требуется включить параметр `client-support`)

:::info Поддержка клиента NetEase
Если вы используете клиент NetEase Minecraft, обязательно включите в `nukkit-mot.yml`:
```yaml
netease-settings:
  client-support: true
```
:::

## Проверка подключения

После успешного подключения:

1. Вы должны увидеть точку спавна сервера
2. В консоли сервера отобразится информация о вашем подключении
3. Вы сможете нормально перемещаться и взаимодействовать с миром

## Возникли проблемы?

Если подключиться не удаётся, обратитесь к разделу [Устранение неполадок](troubleshooting.md).
