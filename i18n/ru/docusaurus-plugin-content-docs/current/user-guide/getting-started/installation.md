# Скачивание и установка

Этот раздел проведёт вас через процесс скачивания Nukkit-MOT и базовой настройки сервера.

## Скачивание Nukkit-MOT

Последнюю версию Nukkit-MOT можно получить из следующих источников:

- [Jenkins CI](https://motci.cn/job/Nukkit-MOT/job/master/lastSuccessfulBuild/artifact/target/Nukkit-MOT-SNAPSHOT.jar) — более быстрый доступ из Китая
- [GitHub Actions](https://github.com/MemoriesOfTime/Nukkit-MOT/actions/workflows/maven.yml?query=branch%3Amaster) — официальные сборки

После скачивания вы получите файл с именем `Nukkit-MOT-SNAPSHOT.jar`.

:::info Примечание
Рекомендуется скачивать сборку с Jenkins CI для более быстрого и стабильного доступа.
:::

## Настройка сервера

### Создание папки сервера

1. Создайте новую папку, например `NukkitServer`
2. Поместите скачанный файл `Nukkit-MOT-SNAPSHOT.jar` в эту папку

### Создание скрипта запуска

Чтобы упростить запуск сервера, нам нужно создать скрипт запуска.

#### Для пользователей Windows

Создайте в папке сервера новый файл с именем `start.bat` со следующим содержимым:

```bat
@echo off
java -Xms1G -Xmx1G -jar Nukkit-MOT-SNAPSHOT.jar
pause
```

#### Для пользователей Linux/macOS

Создайте в папке сервера новый файл с именем `start.sh` со следующим содержимым:

```bash
#!/bin/bash
java -Xms1G -Xmx1G -jar Nukkit-MOT-SNAPSHOT.jar
```

Затем выдайте права на выполнение:

```bash
chmod +x start.sh
```

:::tip Настройка памяти
- `-Xms1G`: задаёт начальный объём памяти 1 ГБ
- `-Xmx1G`: задаёт максимальный объём памяти 1 ГБ
- Настройте значения под свои потребности, например `-Xmx2G` для максимального объёма памяти 2 ГБ
:::

## Первый запуск

### Запуск сервера

- **Windows**: дважды щёлкните по `start.bat`, чтобы запустить его
- **Linux/macOS**: выполните `./start.sh` в терминале

### Ожидание инициализации

При первом запуске сервер:
1. Автоматически создаст файлы конфигурации (`server.properties` и т. д.)
2. Создаст стандартный мир
3. Загрузит необходимые ресурсы

Этот процесс может занять несколько минут.

### Подтверждение успешного запуска

Когда вы увидите сообщение, похожее на следующее, это будет означать, что сервер успешно запущен:

```
[main] [INFO]: Done (xx.xxs)! For help, type "help"
```

### Остановка сервера

После первого успешного запуска рекомендуется остановить сервер для настройки:

Введите в консоли:
```
stop
```

Дождитесь полной остановки сервера, после чего можно переходить к настройке.

## Дополнительно: файлы данных Bin

Если вы планируете использовать плагины с функцией **кастомных блоков**, вам необходимо скачать файлы данных Bin:

1. Скачайте их из [репозитория Bin_Data](https://github.com/MemoriesOfTime/Bin_Data)
2. Поместите папку `bin` в корневую директорию сервера

Ваша директория сервера должна выглядеть так:
```
NukkitServer/
├── bin/                          ← Required for custom blocks
│   ├── vanilla_palette_xxx.nbt
│   └── ...
├── plugins/
├── worlds/
└── Nukkit-MOT-SNAPSHOT.jar
```

:::tip
Если вы не используете плагины, которым требуются кастомные блоки, этот шаг можно пропустить.
:::

## Дополнительно: запуск через Docker

В качестве альтернативы ручной настройке, описанной выше, вы можете запустить Nukkit-MOT с помощью Docker:

```bash
docker run -d --name nukkit-mot \
  -p 19132:19132/udp \
  -p 19132:19132/tcp \
  -v $(pwd)/data:/data \
  -e JAVA_OPTS="-Xms2G -Xmx2G" \
  --restart unless-stopped \
  memoriesoftime/nukkit-mot:latest
```

- Теги `:latest` и `:<короткий-SHA>` — снимки разработки (snapshot), собранные из ветки master.
- Теги вида `:1.26.30-R1` — стабильные релизы, соответствующие Maven Central.
- Все миры, плагины, данные игроков и `server.properties` хранятся в томе `/data`.
