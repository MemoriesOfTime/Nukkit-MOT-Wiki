# Устранение неполадок

В этом разделе описаны типичные проблемы и способы их решения, возникающие при настройке и запуске сервера Nukkit.

## Сервер не запускается

### Описание проблемы
Окно мелькает на мгновение или выводит ошибки при двойном щелчке по скрипту запуска.

### Возможные причины и решения

#### 1. Java не установлена или версия слишком старая

**Способ проверки:**
```bash
java -version
```

**Решение:**
- Убедитесь, что установлена Java 17 или новее
- Обратитесь к разделу [Подготовка](preparation.md), чтобы переустановить Java

#### 2. Несоответствие имени файла JAR

**Способ проверки:**
- Убедитесь, что имя файла JAR в скрипте запуска совпадает с фактическим именем файла

**Решение:**
- Измените имя файла в скрипте запуска или переименуйте файл JAR

#### 3. Повреждённый файл JAR

**Способ проверки:**
- Проверьте, не является ли размер файла аномальным (обычно около 10–20 МБ)

**Решение:**
- Скачайте Nukkit-MOT заново

#### 4. Недостаточно памяти

**Сообщение об ошибке:**
```
Could not reserve enough space for object heap
```

**Решение:**
- Уменьшите объём выделяемой памяти в скрипте запуска (например, `-Xmx512M`)
- Закройте другие программы, интенсивно использующие память

## Игроки не могут подключиться

### Проблемы локального подключения

#### Ограничение петлевого интерфейса в Windows

**Описание проблемы:**
Невозможно подключиться к серверу на том же компьютере.

**Решение:**
Запустите PowerShell от имени администратора и выполните:
```powershell
CheckNetIsolation LoopbackExempt -a -n="Microsoft.MinecraftUWP_8wekyb3d8bbwe"
```

### Проблемы с межсетевым экраном

**Описание проблемы:**
Игроки из локальной или публичной сети не могут подключиться.

**Решение:**

**Брандмауэр Windows:**
1. Откройте «Брандмауэр Защитника Windows»
2. Нажмите «Дополнительные параметры»
3. Создайте новое правило для входящих подключений и разрешите **UDP-порт 19132**

**Linux (ufw):**
```bash
sudo ufw allow 19132/udp
```

**Linux (iptables):**
```bash
sudo iptables -A INPUT -p udp --dport 19132 -j ACCEPT
```

### Порт уже используется

**Сообщение об ошибке:**
```
Address already in use
```

**Решение:**
- Проверьте, не использует ли порт 19132 какая-либо другая программа
- Измените `server-port` в `server.properties` на другой порт

### Клиент NetEase не может подключиться

**Описание проблемы:**
Невозможно подключиться с помощью клиента NetEase Minecraft.

**Решение:**
Включите поддержку клиента NetEase в `nukkit-mot.yml`:
```yaml
netease-settings:
  client-support: true
```
Устаревший ключ `netease-client-support` из `server.properties` автоматически переносится в `nukkit-mot.yml` при запуске.

## Проблемы с плагинами

### Плагин не загрузился (отмечен красным)

**Описание проблемы:**
Название плагина отображается красным при использовании команды `plugins`.

**Возможные причины:**

#### 1. Несовместимость версий
- Плагин не поддерживает текущую версию Nukkit

**Решение:**
- Найдите плагин, поддерживающий текущую версию
- Обновите Nukkit до версии, требуемой плагином

#### 2. Отсутствуют зависимости
- Плагин зависит от других плагинов

**Решение:**
- Проверьте документацию плагина и установите необходимые зависимые плагины

#### 3. Ошибка в файле конфигурации
- В файле конфигурации плагина есть ошибки формата

**Решение:**
- Проверьте сообщения об ошибках в консоли
- Удалите файл конфигурации, чтобы плагин создал его заново
- Исправьте конфигурацию согласно документации плагина

## Проблемы с производительностью

### Подвисания сервера

**Возможные причины:**

#### 1. Недостаточно памяти
**Решение:**
- Увеличьте значение `-Xmx` в скрипте запуска
- Уменьшите количество одновременно подключённых игроков

#### 2. Загружается слишком много чанков
**Решение:**
Уменьшите дальность прорисовки в `server.properties`:
```properties
view-distance=6
```

#### 3. Конфликты плагинов или проблемы с производительностью
**Решение:**
- Отключайте плагины по одному, чтобы найти проблемный
- Обновите или замените плагины с низкой производительностью

## Проблемы с мирами и данными

### Повреждение мира

**Описание проблемы:**
Сервер не может загрузить мир или выводит ошибки.

**Решение:**
1. Остановите сервер
2. Сделайте резервную копию папки `worlds`
3. Попробуйте удалить файлы блокировок в `worlds/world/db`
4. Если устранить проблему не удалось, восстановите данные из резервной копии

### Потеря данных

**Меры профилактики:**
- Регулярно создавайте резервные копии папки `worlds`
- Корректно останавливайте сервер (используйте команду `stop` вместо принудительного закрытия)

## Другие проблемы

### Искажённые символы в консоли

**Для пользователей Windows:**
Добавьте в начало скрипта запуска:
```bat
chcp 65001
```

### Команды не выполняются

**Описание проблемы:**
Введённые в консоль команды не реагируют.

**Решение:**
- Проверьте, не завалена ли консоль большим количеством сообщений об ошибках
- Попробуйте перезапустить сервер
- Проверьте, не вызвана ли проблема каким-либо плагином

## Получение помощи

Если приведённые выше решения не помогли решить вашу проблему:

1. Проверьте полные журналы сервера (папка `logs`)
2. Выполните поиск по тексту сообщения об ошибке
3. Задайте вопрос в [GitHub Issues](https://github.com/MemoriesOfTime/Nukkit-MOT/issues)
4. Присоединитесь к обсуждениям в сообществе, чтобы получить помощь

:::tip При обращении за помощью укажите
- Версию сервера
- Версию Java
- Операционную систему
- Полные журналы ошибок
- Шаги для воспроизведения проблемы
:::
