# server.properties

Измените рабочую конфигурацию сервера, чтобы настроить некоторые базовые функции.

Это стандартные настройки сервера Minecraft, определяемые в файле `server.properties`. Расширенные настройки Nukkit-MOT описаны в [nukkit-mot.yml](nukkit-mot-yml.mdx).

## `motd`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| String     | Minecraft Server      |

имя сервера / текст, который отображается в списке серверов

:::note

не может быть пустым

:::

## `sub-motd`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| String     | Powered by Nukkit-MOT |

вторая строка для motd

:::note

отображается только для игроков из локальной сети при просмотре сервера в списке друзей в игре

не может быть пустым начиная с версии 1.16.210

:::

## `server-port`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Integer    | 19132                 |

порт сервера

:::note

два сервера не могут работать на одном и том же порту

чтобы сервер был доступен из интернета, необходимо настроить проброс портов

Bedrock edition использует UDP

:::

## `server-ip`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| String     | 0.0.0.0               |

IP-адрес сервера

:::note

два сервера не могут работать на одном и том же порту

чтобы сервер был доступен из интернета, необходимо настроить проброс портов

Bedrock edition использует UDP

:::

## `server-ipv6-port`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Integer    | -1                    |

порт для опционального IPv6-прослушивания

:::note

IPv6-прослушивание отключено, если значение — `0` или меньше (по умолчанию `-1`)

чтобы включить его, укажите корректный порт, отличный от `server-port`

:::

## `server-ipv6`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| String     | ::                    |

IPv6-адрес, к которому привязывается опциональное IPv6-прослушивание

должен быть корректным IPv6-адресом; оставьте поле пустым, чтобы отключить IPv6-прослушивание

## `view-distance`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Integer    | 8                     |

максимальная дальность прорисовки в чанках

большее значение = больше загруженных чанков = больше потребление RAM и CPU

## `max-players`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Integer    | 50                    |

Максимальное количество игроков, разрешённых на сервере

## `language`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| String     | eng                   |

язык по умолчанию, который использует Nukkit

## `force-language`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Boolean    | off                   |

принудительное использование переводов на стороне сервера

включайте только в том случае, если у вас есть плагин, реализующий их

## `shutdown-message`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| String     | §cServer closed       |

сообщение, которое отображается игрокам при остановке сервера

используйте `§` для цветов и `§n` для перевода строки

## `gamemode`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Integer    | 0                     |

игровой режим сервера по умолчанию

0 = выживание, 1 = творческий, 2 = приключенческий, 3 = наблюдатель

## `force-gamemode`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Boolean    | on                    |

устанавливать игрокам игровой режим по умолчанию при каждом входе

## `difficulty`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Integer    | 2                     |

сложность сервера по умолчанию (0-3)

## `hardcore`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Boolean    | off                   |

игроки будут забанены при смерти

## `pvp`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Boolean    | on                    |

Определяет, включать ли сражения между игроками (PvP)

## `level-name`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| String     | world                 |

Имя мира по умолчанию

## `level-seed`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| String     |                       |

Сид для мира по умолчанию

## `level-type`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| String     | default               |

генератор, используемый для создания мира по умолчанию, если тот ещё не существует

поддерживаются по умолчанию: default, normal, flat, nether, the_end или void

## `generator-settings`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| String     |                       |

Особые настройки генератора мира для мира по умолчанию

## `spawn-protection`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Integer    | 10                    |

размер зоны спауна в блоках, в которой игроки без прав оператора не могут строить или ломать блоки

## `white-list`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Boolean    | off                   |

разрешать вход на сервер только игрокам из белого списка (whitelist)

используйте команду `/whitelist` или измените файл `white-list.txt`, чтобы добавить игроков в белый список

## `whitelist-reason`
| Тип данных | Значение по умолчанию    |
|------------|--------------------------|
| String     | §cServer is white-listed |

Причина включения белого списка, отображается игрокам при отказе в доступе

## `xbox-auth`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Boolean    | on                    |

требовать аккаунт Xbox для входа

:::note

не обходит требования на стороне клиента

если вы отключите эту опцию (не рекомендуется), установите плагин авторизации, чтобы защитить безопасность аккаунтов игроков

:::

## `encryption`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Boolean    | on                    |

включить сетевое шифрование

рекомендуется включить эту опцию, если вы не используете прокси-ПО

## `force-resources`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Boolean    | off                   |

заставлять игроков скачивать ресурспак сервера, если они хотят зайти на сервер

## `force-resources-allow-client-packs`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Boolean    | off                   |

не отключать собственные паки клиента при включённом force-resources

## `spawn-animals`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Boolean    | on                    |

включить спавн животных

## `spawn-mobs`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Boolean    | on                    |

включить спавн монстров

## `allow-flight`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Boolean    | off                   |

включение / отключение возможности полёта для игроков

:::note

если игроков часто исключает за полёт, попробуйте установить значение `on`

:::

## `auto-save`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Boolean    | on                    |

автоматически сохранять мир и данные игроков

:::note

если эта опция отключена, изменения в мирах не сохраняются автоматически даже при выгрузке; при необходимости используйте плагин для ручного сохранения

:::

## `enable-rcon`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Boolean    | off                   |

включить доступ к удалённой консоли

:::note

rcon — не самый безопасный способ удалённого управления сервером

rcon использует тот же порт, что и сервер (но по протоколу TCP)

:::

См.: https://developer.valvesoftware.com/wiki/Source_RCON_Protocol

## `rcon.password`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| String     | Случайные 10 символов |

Пароль для RCON-подключений

## `rcon.port`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Integer    | 25575                 |

Порт для RCON-подключений

## `enable-query`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Boolean    | on                    |

включить расширенные запросы (query)

## `server-authoritative-movement`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| String     | server-auth           |

Серверно-авторитарное движение

Возможные значения: `client-auth / server-auth-with-rewind / server-auth`

## `server-authoritative-block-breaking`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Boolean    | on                    |

Серверно-авторитарная обработка разрушения блоков

## `server-authoritative-inventory`
| Тип данных | Значение по умолчанию |
|------------|-----------------------|
| Boolean    | on                    |

Серверно-авторитарные транзакции инвентаря (ItemStackRequest)

действует только для клиентов с протоколом [1.16.100](https://minecraft.wiki/w/Bedrock_Edition_1.16.100) и выше

:::note

это аналог серверно-авторитарного движения для инвентаря — сервер проверяет перемещения предметов вместо того, чтобы доверять клиенту

:::
